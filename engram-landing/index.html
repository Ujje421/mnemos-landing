How it works

Three steps to persistent memory.

01

Point Mnemos at your project

Mnemos scans your codebase, configs, docs, and git history. It builds a structured knowledge graph of everything your AI needs to know. Embeddings are generated locally — nothing leaves your machine.

terminal
$ mnemos init ./my-project
Scanning project structure…
Found: 247 source files, 12 configs, 3 schemas
Generating local embeddings…
Building knowledge graph…
✓ 1,847 knowledge fragments indexed
✓ MCP server running on localhost:3847
02

Connect any AI tool

Mnemos exposes a local MCP server. Connect it to Claude, VS Code, Cursor, or any MCP-compatible tool. One config line. Your project memory becomes universally accessible.

claude_desktop_config.json
{
"mcpServers": {
"mnemos": {
"command": "mnemos",
"args": ["serve", "--project", "./my-project"]
}
}
}
03

AI already knows your project

Ask any question. Mnemos retrieves the relevant context — architecture decisions, schemas, conventions — and injects it automatically. The AI responds as if it's been working on your project for months.

Principles

Built different.

Desktop-first

A native application, not a browser tab. Fast, reliable, always available in your system tray.

Local-first

Your data lives on your machine. Embeddings generated locally. No server required to function.

Privacy-first

No code ever leaves your device. Cloud sync is optional and end-to-end encrypted. Your keys, your data.

Git-native

Understands commits, branches, and history. Extracts decisions from your actual development workflow.

Model-agnostic

Works with Claude, GPT, Gemini, Llama, or any model. Your memory is not locked to one provider.

MCP-compatible

Built on the Model Context Protocol. Integrates with any MCP-compatible AI tool out of the box.

Why we're building Mnemos.

As developers, we spend hours every week managing context instead of writing code. We found ourselves constantly copy-pasting the same architectural decisions, database schemas, and API rules into Claude, Cursor, and ChatGPT.

The models were getting smarter, but they were trapped in isolated, amnesiac sessions.

We realized that the next major breakthrough in AI-assisted development wouldn't come from a larger context window. It would come from a persistent memory layer. A stateful system that lives alongside your codebase and understands how your project evolves.

We are a small team of engineers building the tool we desperately wanted for ourselves. If you feel the same pain, join us.
